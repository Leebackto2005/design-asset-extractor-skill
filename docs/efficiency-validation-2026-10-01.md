## 离线行为

Python 3.12.14，沿用固定依赖。bootstrap 运行 self-test、test_workflow.py、test_parallel.py、test_portrait.py、test_efficiency.py。

新增效率检查包括：

- 1、8、12、13 项分页与 ID 顺序，不看图时没有自动 PASS；人像、生成式结果、复杂分割、小主体、明确存疑及旧预览转单项。
- accept/reject/detail 混合提交；缺项、重复 ID、空观察、错误索引及被修改的候选/审核图/预览/拼版拒绝放行。
- 第二次移动时模拟中断，整批 pending_review 保留，重放后恢复三个 PASS；两个独立 CLI 进程竞争同一批，均完成且没有重复或丢失记录。
- 同命令同文件只完整 hash 一次，写入后失效；跨命令即使恢复 mtime、大小相同也重新检查；verify 绕过 memo。
- finalize 每个未改变文件一次完整读取；五个候选共享源图一次完整解码。
- 缓存首次产生缩略图，命中时不重新完整解码；意图、尺寸、版本、内容变化或强制刷新不复用发现。损坏计划失效、篡改缩略图被拒绝并可重新生成。
- 非完整发现与错误来源不可缓存；源图变化拒绝旧规范计划；奇数尺寸缩略图映射及 EXIF 校正一致。

这些测试中的审核决定是合成夹具，仅验证事务，不证明真实图像质量。原并发和人像回归继续运行；本次没有真实人像或新图片生成调用。

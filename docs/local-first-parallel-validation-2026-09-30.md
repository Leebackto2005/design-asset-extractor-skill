# 脚本优先与自适应并行：实施及验证

日期：2026-09-30。

默认工作流已改为：**大模型识别素材并提供提取参数 → Python 脚本批量并行处理 → 原图、Alpha、深浅背景复核 → 交付透明 PNG**。

## 实际行为

- 新任务默认 `build --workers 5 --processing local-first`；线程数为候选数量与配置上限的较小值，可设置任意正整数上限。
- Codex 提供类别、源图坐标 bbox、本地方法及背景色/前景点/背景点；脚本不负责语义识别，不下载额外分割模型。
- 多图发现与素材复核可分发 subagent，受宿主实际 agent 名额限制；脚本线程数独立于 agent 数量。一个候选时直接处理。
- 默认普通本地提取失败、缺少本地方法的 B/extract 都转人工。仅明确 B/complete 且允许修补的候选可登记生成式补全；AUTO 误带 complete 也不能触发生成式回退。
- 显式 `--processing builtin-repair` 可选择原生成式分离/修补行为；未记录并发上限的历史任务按单路处理。
- 任务记录通过操作系统文件锁保护。本地 worker 只写自己的素材文件，由主线程按原计划顺序保存记录。必要的图片请求在锁外执行，登记成功才可发出。
- 图片结果必须关联任务目录、素材 ID 与尝试编号；每个素材最多两次请求。结果不明保持阻塞并占用名额，只恢复原请求，迟到结果不能覆盖新尝试。
- 内置图片工具没有暴露模型选择参数，不声称锁定某个具体图片模型。

## 离线验证

以下为测试观测值，合成素材验证未调用图片提供方。线程测试使用同步屏障检查实际任务重叠，并与串行提取结果逐像素比较。

| 候选数 | 配置上限 | 实测同时进入 worker 数 | 与串行像素一致 |
|---:|---:|---:|---|
| 1 | 5 | 1 | 是 |
| 2 | 5 | 2 | 是 |
| 5 | 5 | 5 | 是 |
| 8 | 5 | 5 | 是 |
| 7 | 3 | 3 | 是 |
| 8 | 7 | 7 | 是 |
| 3 | 1 | 1 | 是 |

多进程测试通过：6 个请求竞争 2 个名额只登记 2 个；7 个请求竞争 5 个名额只登记 5 个；两个进程竞争同一素材只登记一次。还覆盖乱序导入与复核、阻塞恢复、迟到编号、缺少编号、两次请求上限、原生 Alpha 保留、旧命令兼容、禁止新任务绕过尝试记录、交付哈希校验。

默认模式混合测试最终为 2 PASS、4 MANUAL：可提取 A 与获授权的 B/complete 通过；普通失败、B/extract、严格禁止补全及误标 AUTO/complete 均不能调用图片工具。B/complete 仅使用保存的合成回图验证导入协议，无实际生成请求。

独立环境 bootstrap 的自测、工作流回归、并发回归全部通过。最终收紧 AUTO/complete 边界后，受影响的完整并发回归再次通过。Skill 格式校验与差异空白检查通过。

## 真实原图：五素材本地提取

使用已有几何原图中的方块、箭头、自由形状、圆环、三阶阶梯。Codex 查看实际原图与候选，复用已验证的定位和选点指导，脚本以 5 个 worker 执行 matte，全部禁用生成式修补。

| 指标 | 实测结果 |
|---|---|
| 素材数 | 5 |
| 本地 worker 配置/实际启动数 | 5 / 5 |
| 视觉复核通过 | 5 PASS |
| 人工项及未完成项 | 0 |
| 图片生成调用 | 0 |
| build 墙钟时间 | 0.9439754 秒 |
| 最终交付校验 | 25 个索引文件通过 SHA-256 校验 |

build 时间使用 `time.perf_counter` 测量，包含 CLI 启动、源图快照、提取、任务记录与预览写入，**不包含大模型识别及交互看图复核时间**。实际 worker 重叠由上述离线屏障测试验证；本次真实 build 未单独插桩每个 worker 的起止时间，不据此承诺固定提速倍数。

逐项查看源裁切、浅底、深底及透明 PNG 后，确认方块渐变和圆角、箭头深紫侧面与朝向、自由形状轮廓、圆环内孔及阶梯透视保留；邻近叶尖、天空、圆环与阶梯碎片已移除。圆环内孔采样 RGBA 为 `(0, 0, 0, 0)`。只有通过复核的 PNG 进入 assets。

本地 matte 使用原图可见像素并处理 Alpha/边缘颜色，不能据此声称全图所有像素完全不变；被遮挡部分没有原像素，独立补全仍是生成式重建。

## 保留的图片工具试验

改变默认路线之前，曾对同一原图的五个独立候选测试内置图片工具：共 8 次请求，最终 2 PASS、3 MANUAL。请求开始/结束记录显示最多有 3 个工具调用等待区间重叠；这不证明提供方内部同时执行了 3 个生成任务，也没有验证 5 路生成并发。

圆环与阶梯通过；箭头、方块、自由形状在两次尝试后仍有边距或低 Alpha 碎点问题，保留人工任务，未计入成功素材。试验已 finalize/verify，55 个索引文件校验通过。默认路线随后改为脚本优先，没有继续为这些对象发起生成请求。

## 使用与边界

```text
使用 $design-asset-extractor 识别这张图中的可复用素材，
用脚本批量处理，最多 5 个一起提取，检查后交付透明 PNG。
只有明确需要遮挡补全的素材才使用内置图片工具。
```

Python 3.12 与固定依赖的独立环境仍由 `scripts/bootstrap.ps1` 创建。当前本地方法为 matte、完整矩形照片 crop、浅色背景深色主体 bright-background。复杂背景、透明透射、反射及不能可靠分离的对象仍保留人工，不承诺任意图片或人像均可自动成功。

执行接口见 [workflow](../references/workflow.md)。任务文件、真实回图与本地完整测试日志保留在运行机器的交付目录，不将用户原图及机器路径提交到公共仓库。

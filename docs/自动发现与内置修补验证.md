# 自动候选发现、A/B/C 分流与内置图像修补

更新日期：2026-09-11。此记录描述第二版，第一版报告保留历史范围。

## 已实现

- Codex 接收图片或文件夹，自动枚举、看图、发现候选、填写坐标与分流计划；用户不必准备 JSON。
- A：本地原像素去底；质量检查失败可进入 B，保留失败原因，I/O 等运行异常仍为 ERROR。
- B：Codex 从队列取得提示词与裁切图，调用内置 image_gen，自动导入回图并复核。extract 只分离完整对象；complete 补全遮挡部分。
- C：复杂透明、严重缺失或要求严格原像素而不可可靠处理的素材，保留人工任务。
- 原生透明通道原样保存，输出前检查并生成原图/浅底/深底三联预览。
- 首次质量不合格可以自动重试一次；最多两次请求。保留每次提示词、产物、来源哈希和复核结论。
- 中断、超时或未知工具结果记为 REPAIR_BLOCKED，避免重复请求；找到原结果可接回同次尝试。

## 内置工具与模型名称

使用当前 Codex 会话的内置图片工具，不使用 API Key，不自动控制网页。内置接口没有暴露模型选择参数，因此本次实际记录 model=null。不能将其描述为已锁定或已验证 Images 2.5。

自动发现和内置调用由 Codex 在 Skill 执行过程中完成；Python 提供输入枚举、任务保存、队列和回图处理，单独运行脚本不是无人值守视觉服务。

## 实际验证

使用用户海洋素材图中的三个代表性候选，不宣称全图全部提取完成：

| 候选 | 路线 | 当前结果 |
|---|---|---|
| 被叶片遮挡的扇贝 | B / complete | 一次实际内置工具调用，得到 1274 × 1235 透明 PNG，经原图与深浅底对照后 PASS |
| 海龟 | B / extract | 实际调用被用户中断，生成目录未找到海龟输出，结果未知；REPAIR_BLOCKED，无重复调用 |
| 透明气泡 | C | 因原天空混色与透射关系，保留人工处理任务 |

扇贝结果是生成式补全版本，补全部分需要设计师判断，不是恢复不可见原像素。生成像素尺寸也不代表源图细节无损放大。

## 使用

在 Codex 中提供图片并说：

> 使用 $design-asset-extractor 自动发现素材、按 A/B/C 分流，并用内置图片工具修补，检查后交付透明 PNG。

正常队列由 Codex 自动继续；发生工具阻塞会报告真实原因。命令格式见 [执行接口](../references/workflow.md)，无需用户手写计划。

# 人像抠图与上半身构图

仅在用户明确要求人像抠图、补齐肩膀或上半身构图时使用。用户不用写坐标、头部蒙版或 JSON。Codex 看图、标定与复核，Python 负责面积计算与确定性的裁切、平移和透明画布。

## 发现、提取与补全

沿用 inventory/plan/build 接口，候选增加布尔值 `portrait: true`。单张图直接处理，多张图沿用并发与 subagent 分工，最多生成请求数仍为每个素材两次。

- 已有真实 Alpha：A/AUTO，`extraction_method: native-alpha`，可设 padding=0；检查透明主体后原样保留 RGBA，不再次按颜色抠图。此方法仅用于人像模式，不添加外围边距。
- 简单背景：A/matte 或适用的 bright-background；确认发丝、皮肤、浅色衣服未被误删。人像本地失败可进入 B，严格 repair_allowed=false 则转人工。
- 复杂背景或难分离的发丝：B/IMAGE2、repair_mode=extract，明确写主体分离提示词。此处允许在 local-first 模式调用工具，普通 B/extract 仍转人工。
- 缺少肩部或身体：B/IMAGE2、repair_mode=complete，一次请求补齐双肩、胸部上段并输出透明人像。工具返回主体四周先留空，不需要它精确实现最终构图。

不要只因图片中有人就建人像候选。用户只要求抠图时不自行补画本来不需要的身体；用户要求上半身构图且身体缺失时才补。保留本人身份、五官、发型、表情、原姿态及可见服装，不换装、美颜、改脸或将侧脸改成正脸。不能保证生成工具严格保留原像素；身份或可见结构改变就拒绝，最多再请求一次。repair_allowed=false 始终禁止生成式处理。

所有生成使用 repair-start、明确参考图路径、repair-result --attempt N。未知结果保持阻塞，只恢复原请求；不要另外请求分割模型、API 或网页。补全是生成式内容，不是恢复原像素。原图、原始工具回图与最终构图分别保存。

## 面积与构图参数

默认目标：3:4 竖版透明 PNG，头部实际轮廓面积约占整张画布 40%。60% 仅为可选参考，不必生成或保存中间版本。

头部含头顶发型、脸和耳朵，止于下巴；不计垂到肩部的长发、帽子或颈部。Codex 在实际提取图/回图上标定轮廓多边形。多边形与主体 Alpha 相交后，将每个像素 Alpha/255 相加作为头部面积，再除以最终画布面积。这是模型轮廓的估计，不是自动人脸识别或精密生物测量。查看保存的蒙版和红色区域预览，确认轮廓没有只圈住脸部、漏发型或包含身体。

从 status 找到 review 图，查看它的实际尺寸与像素坐标。生成构图 JSON；点和区域均使用**构图前审核 PNG**的坐标，右下边界不包含。input_sha256 使用该 PNG 的 SHA-256，不是原图或最近回图的哈希。

```json
{
  "input_sha256": "实际审核PNG的SHA-256",
  "head_polygon": [[80, 30], [220, 30], [235, 110], [210, 180], [90, 180], [65, 110]],
  "upper_body_bbox": [0, 0, 300, 390],
  "target_head_area_ratio": 0.4,
  "aspect_ratio": [3, 4]
}
```

坐标仅说明格式。upper_body_bbox 保留整个头部、颈部、双肩和胸部上段；只允许裁去底部多余躯干，不允许从上方或两侧裁掉可见主体。缺失的头顶或肩部需要先解决，不以扩大透明边距掩盖缺失。

```text
python scripts/asset_job.py portrait-layout --job 任务目录 --id 人像ID --layout 构图参数.json
```

脚本不放大或拉伸人像，只选择下部裁切并平移原 RGBA 到整数像素比例画布。头部水平居中，顶部至少留 5%，双肩两侧至少留 3%。优先完整身体，目标允许 ±3 个百分点；空间不足时扩大画布并降低占比，报告 actual_head_area_ratio 和 adjustment_reason。面积按最终画布核对，不再添加通用外边距。

胸部允许在最终底边自然截断。头发和双肩不能触及上、左、右边界；普通素材仍禁止四边前景触边。默认保持原分辨率，不额外承诺正式证件照尺寸或印刷规格；用户指定画幅可覆盖 aspect_ratio，像素尺寸保持自适应。

## 状态、复核与交付

portrait-layout 只接受 REVIEW 且没有 pending_review 的人像。脚本使用任务锁，保存构图前 input.png、layout.json、head-mask.png、head-preview.png、比例记录与哈希，再更新审核 PNG、Alpha 和深浅底预览。

构图中断时 status 返回 pending_portrait；使用其 layout_path 指向的原参数恢复，不能先换参数或审核。相同参数重复执行不会累积裁切或 Alpha 变化。需要调整构图时仍对保存的原始 input.png 标定，使用记录的 input_sha256，不对已构图 PNG 重复估计坐标。不同参数保存为独立目录，保留先前证据。

新一次生成回图将清除当前构图记录，必须根据该次回图重新标定；旧蒙版不能直接套用。严格核对尝试编号和图片哈希，防止迟到结果或旧参数串图。

审核前查看：用户原图、生成/本地提取图、最终构图、头部蒙版、浅底和深底。检查身份、五官、发丝、服装、肩部完整度、透明边缘和比例。比例合理但人物变脸不能通过；比例低于目标时确认是身体完整与留白造成，向用户解释实测值。普通数值构图调整用 portrait-layout 修正，不为比例问题反复生成。

```text
python scripts/asset_job.py review --job 任务目录 --id 人像ID --decision accept --note "实际对照原图、蒙版及深浅底的观察；记录比例调整和生成式身体来源"
python scripts/asset_job.py finalize --job 任务目录
python scripts/asset_job.py verify --job 任务目录
```

没有完成构图或存在待恢复构图不能接受和交付。最终交付记录包含画幅、目标/实测占比、头部蒙版、输入和参数哈希、生成式来源及调整原因；所有图像与记录纳入交付校验。

离线验证 `python scripts/test_portrait.py` 使用合成轮廓，仅证明比例与流程。真实验收必须用用户提供的人像，不能把合成测试或宣传图说成真实效果。
